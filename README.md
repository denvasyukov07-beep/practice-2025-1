📖 О проекте
Этот репозиторий создан для выполнения задания по проектной (учебной) практике студентами 1‑го курса ИТ- и ИБ‑направлений.

Проект представляет собой статический веб-сайт, созданный на генераторе Hugo, который посвящён интерактивной образовательной визуальной новелле «SimplePhysics». Цель сайта — показать абитуриентам, что физика может быть увлекательной, наглядной и даже немного игровой.

Основные разделы сайта:

Главная страница: аннотация проекта, рассказывающая о том, что такое визуальная новелла «SimplePhysics» и как она помогает изучать физику.

Страница «О проекте»: подробное описание сюжета новеллы, её персонажей и тех физических концепций, которые можно освоить в процессе игры.

Страница «Участники»: информация о команде разработчиков и их вкладе в проект.

Раздел «Тест»: интерактивный тест, позволяющий узнать, какой персонаж из вселенной «SimplePhysics» подходит пользователю.

🛠 Технологии
Hugo — генератор статических сайтов (рекомендованный в задании инструмент).

HTML / CSS — для базовой вёрстки и стилизации.

Markdown — для написания контента и документации.

Git — система контроля версий.

GitHub Pages — платформа для хостинга готового сайта.

🚀 Быстрый старт
Для того чтобы развернуть и запустить сайт локально, выполните следующие шаги.

1. Клонирование репозитория
bash
git clone https://github.com/denvasyukov07-beep/practice-2025-1.git
cd practice-2025-1
2. Установка Hugo
Убедитесь, что на вашем компьютере установлен Hugo. Если нет — скачайте его с официального сайта или воспользуйтесь менеджером пакетов.

3. Запуск локального сервера
bash
hugo server
После запуска сайт будет доступен по адресу: http://localhost:1313.

Для просмотра черновиков (draft-страниц) используйте флаг -D:

bash
hugo server -D
4. Сборка статического сайта
Чтобы сгенерировать финальную версию сайта в директории public/, выполните:

bash
hugo
🌐 Деплой на GitHub Pages
Сайт автоматически публикуется с помощью GitHub Actions при каждом пуше в ветку master. В репозитории настроен workflow-файл в папке .github/workflows/, который:

Запускает сборку Hugo с правильной конфигурацией.

Публикует содержимое папки public/ в ветку gh-pages (или непосредственно на GitHub Pages).

Таким образом, сайт всегда доступен по адресу, указанному в hugo.toml:

https://denvasyukov07-beep.github.io/practice-2025-1/

В рамках вариативной части команда реализовала интерактивную визуальную новеллу по физике. Это позволило:

применить на практике знания HTML, CSS и Hugo;

разработать уникальный образовательный контент (сюжет, персонажи, тест);

интегрировать простые физические симуляции в интерактивные сцены.
