Полезные ресурсы

Материалы, которые нам помогли

Здесь собраны ссылки, которые могут быть полезны тем, кто интересуется проектом, хочет разобраться в теме или внести свой вклад.

  • 🎓
    Московский Политехнический Университет

    Наш университет, в котором мы учимся и на базе которого создаётся проект «SimplePhysics». На сайте можно узнать о поступлении, программах и жизни вуза.

  • 💻
    Исходный код проекта

    Репозиторий сайта визуальной новеллы на GitHub. Здесь хранятся все файлы, история изменений и документация.

  • 📘
    MDN Web Docs

    Полный справочник по HTML, CSS и JavaScript. Помог нам освоить вёрстку и разобраться с тонкостями стилей.

  • 📙
    Дока

    Добрый справочник по веб-разработке на русском. Простые объяснения сложных тем, примеры кода.

  • ⚙️
    Курс по Git (Хекслет)

    Бесплатные уроки, с которых мы начинали изучать систему контроля версий. Рекомендуем всем, кто хочет работать в команде.

  • 🧪
    Build Your Own X

    Коллекция руководств «Создай свой…» — интерпретатор, HTTP-сервер, базу данных. Мы черпали вдохновение для технической части проекта.

  • 🌐
    Документация Hugo

    Официальный сайт генератора статических сайтов, на котором построен наш ресурс. Много готовых решений и инструкций.
